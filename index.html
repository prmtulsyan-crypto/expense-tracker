Setup & Sync

Connect your Google Sheet

One-time Google Sheets setup

Follow these steps once. After that, all your expenses sync automatically to your Google Sheet — accessible from any device.

1
Create a Google Sheet

Go to sheets.new and create a new spreadsheet. Name it "Expense Tracker 2026".

2
Open Apps Script

In your sheet: Extensions → Apps Script. Delete all existing code.

3
Paste the script

Copy the contents of apps-script.gs (provided alongside this file) and paste it into the Apps Script editor. Click Save (Ctrl+S).

4
Deploy as Web App

Click Deploy → New deployment → Type: Web app. Set "Execute as" to Me and "Who has access" to Anyone. Click Deploy and authorize. Copy the Web App URL.

5
